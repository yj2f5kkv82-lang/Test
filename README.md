# fun.py

ASCII art banners and edgy intellectual jokes, from the command line.

No dependencies. Python 3 only.

## Usage

```bash
# Banner + random joke
python fun.py

# Custom banner + random joke
python fun.py --banner "HELLO"

# Just a joke
python fun.py --joke
```
